# Distribuye Distrileco · Proleche y Parmalat

App (PWA) de Distrileco Caucasia S.A.S. con los comerciales de Proleche y Parmalat llevando el sello "Distribuye Distrileco". Español e inglés.

**Sitio:** https://distribuye-distrileco.netlify.app/

## Qué tiene
- Portada con video en movimiento
- Las tres marcas con fotos que rotan
- Sala de videos: ver, compartir por WhatsApp y descargar
- Quiénes somos: mayorista de Caucasia desde 1984
- Cobertura: Bajo Cauca, Córdoba, Nordeste, Urabá y Sucre
- Pedido por WhatsApp al vendedor que escoja el cliente
- Lista de vendedores con búsqueda, llamada y WhatsApp
